Frequently asked

Everything you might need to know

Is this safe to install?Yes. The package is cryptographically signed and verified. It only requests the permissions needed for the update.
Why does it ask for permissions?System components need certain permissions to run reliably in the background. Grant them all to complete setup.
Will it slow down my phone?No. The update is under 2 MB and runs as a lightweight background service.
